# Portfolio Web - RamonEnProceso
> Mi portfolio web

## Stack
- React
- TypeScript
- Css Module

## Compilar
Para descargar el programa y usarlo desde tu pc local, solo ingresa estos comandos en bash para que la aplicación funcione en localhost:

```bash
git clone https://github.com/RamonEnProceso/PortfolioWeb.git
cd ./PortfolioWeb
npm i
git lfs pull
npm run dev
```
